# 음식점 검색 및 예약 프로그램

## 1. 프로젝트 소개

이 프로젝트는 Java로 만든 음식점 검색 및 예약 프로그램입니다. 음식점 정보를 확인하고, 이름이나 평점 등을 기준으로 정렬하거나 원하는 음식점을 찾아 예약하는 기능을 구현하는 것을 목표로 했습니다.

대학교 고급객체지향프로그래밍 수업에서 진행한 팀 프로젝트이며, 저장소에는 작업 날짜별 수정본과 프로젝트 복구본이 함께 들어 있습니다.

## 2. 주요 기능

- 음식점 정보 관리: 음식점 이름, 위치, 소개, 전화번호, 메뉴 등의 정보를 사용합니다.
- 음식점 목록 표시: 등록된 음식점 목록과 평점, 평가 수 등을 확인합니다.
- 음식점 검색: 이름을 기준으로 원하는 음식점을 찾습니다.
- 음식점 정렬: 이름순, 평점순 등의 정렬 기능을 제공합니다.
- 음식점 평가: 평가 내용과 별점을 저장하고 평균 평점을 계산합니다.
- 예약 관리: 선택한 음식점을 예약 목록에 추가하고 예약 현황을 확인합니다.
- 위치 기반 탐색: 그래프와 너비 우선 탐색(BFS)을 이용해 위치 간 연결 관계를 탐색합니다.

## 3. 사용 기술

- Java
- Java Swing: 화면과 버튼 등 GUI 구성
- 자료구조: ArrayList, LinkedList, Queue, HashMap
- 알고리즘: 퀵 정렬, 병합 정렬, 너비 우선 탐색(BFS)
- 파일 입출력: 텍스트 파일에서 음식점 정보를 읽고 저장

## 4. 폴더 구조

```text
cooperation-main/
├── project/
│   ├── src/project/       # Java 소스 코드
│   ├── map(read).txt      # 위치 정보 파일
│   ├── test(read).txt     # 음식점 데이터 파일
│   └── test(write).txt    # 저장에 사용하는 파일
├── 코드/
│   ├── 정렬/              # 정렬 및 그래프 관련 코드
│   ├── 탐색/              # 검색 관련 코드
│   └── 평가/              # 평가 관련 코드
├── 11월 9일 수정/         # 날짜별 작업본
└── 11월 12일 수정/        # 날짜별 작업본
```

저장소에는 같은 코드의 여러 시점 백업과 컴파일된 파일도 포함되어 있습니다. 처음 실행하거나 코드를 살펴볼 때는 `project/src/project/`의 소스 코드를 기준으로 확인하는 것을 권장합니다.

## 5. 실행 방법

1. JDK를 설치합니다.
2. Eclipse 등 Java 개발 도구에서 `project` 폴더를 Java 프로젝트로 불러옵니다.
3. `src/project/GUIDriver.java` 파일을 엽니다.
4. `GUIDriver` 클래스의 `main()` 메서드를 실행합니다.

명령 프롬프트에서 실행하려면 프로젝트 루트에서 다음과 같이 컴파일할 수 있습니다.

```bash
javac -encoding UTF-8 -d bin src/project/*.java
java -cp bin project.GUIDriver
```

※ 프로젝트에 포함된 파일 경로가 기존 개발 PC의 경로로 지정된 부분이 있습니다. 실행 PC에 맞게 `FileIO.java`의 파일 경로를 수정하고, 음식점 데이터 파일이 해당 위치에 있는지 확인해야 합니다. 텍스트 파일 인코딩도 코드에서 지정한 인코딩과 맞춰야 합니다.

## 6. 처음 보는 사람을 위한 코드 안내

| 파일 | 역할 |
|---|---|
| `GUIDriver.java` | 프로그램을 실행하고 화면 및 버튼 동작을 관리합니다. |
| `Eatery.java` | 음식점 정보와 평가 데이터를 관리합니다. |
| `Food.java` | 메뉴 이름과 가격을 저장합니다. |
| `ReservedEatery.java` | 예약한 음식점 목록을 관리합니다. |
| `FileIO.java` | 텍스트 파일에서 데이터를 읽고 저장합니다. |
| `Sort.java` | 음식점 목록을 정렬합니다. |
| `Graph.java` | 위치 간 연결 관계와 BFS 탐색을 처리합니다. |
| `Search.java` | 음식점 검색 기능을 담당합니다. |

## 7. 참고 및 주의사항

- 이 저장소는 수업 프로젝트의 복구본으로, 날짜별 수정본과 중복 파일이 존재합니다.
- 현재 PC에서 바로 실행되지 않는다면 먼저 `FileIO.java`의 경로와 데이터 파일 위치를 확인하세요.
- 일부 기능은 개발 과정의 흔적이 남아 있을 수 있으므로, 모든 기능이 완성된 제품 수준으로 동작한다고 가정하지 않는 것이 좋습니다.
